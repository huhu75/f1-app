# Suivi des évolutions dans le README

À chaque modification du projet (fonctionnalité, correctif, refonte, changement du schéma Supabase ou des dépendances), mettre à jour `README.md` dans le même changement, avant de commiter :

- Ajouter l'évolution en haut de la section « 📝 Évolutions », sous la date du jour au format `AAAA-MM-JJ`. Si une entrée existe déjà pour cette date, compléter cette entrée au lieu d'en créer une nouvelle.
- Une ligne par évolution, en français, courte et centrée sur ce qui change (pour les joueurs ou pour la maintenance).
- Corriger aussi les autres sections du README que la modification rendrait inexactes (installation, schéma, configuration des joueurs…).
